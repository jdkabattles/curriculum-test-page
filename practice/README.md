# Daily GitHub Practice — Creative Writing + Advanced Artwork

Practice ground for the master-blogger curriculum. GitHub is the sketchbook,
Blogger is the shop window. Nothing here is a published post, and nothing
moves to a live blog without its own approval.

## Daily routine (30 minutes total)

1. **Creative writing (~15 min)** — one new blog idea, to the playbook standard:
   a 3C title (Clear / Clickable / Contextual), the direct answer first,
   the hook line after the answer, a plain-text "In this post" H2 outline,
   and the Section 9 end block (one specific comment question + one email line).
2. **Advanced artwork (~15 min)** — one artwork study for that idea or a study
   theme: hero or vertical diagram, hero <200 KB, in-article <100 KB, WebP
   first, alt text that describes the frame, one distinct caption. Judge it in
   the file: what it is, budget pass/fail, and what it taught.

## Rules

- One dated file per day, committed the same day. A missed day is missed,
  not backdated.
- Never invent a payout, term, or personal-result story in a practice idea.
- Vetoed techniques (live 3D hero, autoplay video-loop hero, depth-map/parallax
  hero) may be STUDIED here as files. Studying them does not overturn their
  Section 4 veto on referral posts, and a study file is never copied straight
  into a Blogger post.
- A practice idea becomes a post only after the Section 1 screen (real search
  phrasing, one intent), verified official terms for any money topic, the
  Section 4 verdicts, and Jonathan's publishing approval.

## Daily file template

Date / Idea title (3C check) / Answer first / Hook after answer /
H2 outline / End block (comment question + email line) /
Artwork study (what, file, size, budget pass/fail, lesson) /
What to keep, what to drop.
